# Схемный аналог магниторотационной неустойчивости (МРН)

Код: `code/mri_circuit.py` (линейная теория + квантовая динамика), `code/make_fig_mri.py`.
Данные: `data/mri_circuit_*.json`. Рисунок: `figs/fig_mri_circuit.pdf`.

## Гамильтониан
Две потоковые (фазовые) координаты φ₁, φ₂ с зарядовой энергией E_C. На узле 1 стоит π-переход E(φ₁):
DMRG-кривая сильного перехода, t_J = t, U = 6t, с максимумом при φ₁ = 0. Оба узла шунтированы индуктивными
«пружинами» K, узлы связаны гиратором (однородное «магнитное поле» γ в плоскости (φ₁, φ₂), симметричная калибровка):

    H = E_C (p₁ + γφ₂/2)² + E_C (p₂ − γφ₁/2)² + K(φ₁² + φ₂²)/2 + E(φ₁),   [φ_j, p_j] = i.

Уравнения движения (v_j = φ̇_j, ω_c = 2E_Cγ):
v̇₁ − ω_c v₂ = −2E_C(Kφ₁ + E′(φ₁)),  v̇₂ + ω_c v₁ = −2E_C Kφ₂.

Для E′ = −k_t φ₁ (k_t = |E″(0)| = 0.153 t) это уравнения Хилла (shearing sheet):

| диск (МРН) | цепь |
|---|---|
| Кориолис 2Ω | гиратор ω_c = 2E_Cγ |
| приливный член −dΩ²/d ln r = 2qΩ² | отрицательная жёсткость π-перехода ω_t² = 2E_C k_t |
| магнитное натяжение k²v_A² | индуктивная пружина ω_K² = 2E_C K |
| эпициклическая частота κ² | ω_c² − ω_t² |

## Линейная теория (численно проверено)
Дисперсия: ω⁴ − ω²(ω_c² − ω_t² + 2ω_K²) + ω_K²(ω_K² − ω_t²) = 0.
* Неустойчивость при 0 < K < k_t для любого гиратора (теорема Кельвина–Тэта–Четаева: нечётное число
  отрицательных жёсткостей гироскопически не стабилизируется).
* При K = 0 система устойчива, если ω_c > ω_t (аналог критерия Рэлея: κ² > 0).
  Слабая пружина разрушает гироскопическую стабилизацию — это и есть механизм МРН.
* Максимальный инкремент s_max = ω_t²/(2ω_c) (численно точно; аналог Балбуса–Хоули ½|dΩ/d ln r|),
  достигается при K ≈ 0.4–0.5 k_t. Без гиратора инкремент √(ω_t² − ω_K²), максимум ω_t при K → 0.

## Квантовая адиабатическая динамика
E(φ₁) — адиабатическая (BO) энергия электронов из DMRG; E_C = ħω g² = 4.3·10⁻⁵ t (мода из основного расчёта:
ħω = 0.003 t, g = 0.12); ω_t = 3.6·10⁻³ t; гиратор ω_c = 3ω_t. Split-operator на сетке 512² по (φ₁, φ₂).
Начальное состояние — гауссиан в симметричной точке φ = 0.
Проверка: начальный рост ⟨φ₁²⟩ в обычной петле 2s = 5.07·10⁻³ против классических 5.14·10⁻³.

| случай | K/k_t | ω_c/ω_t | классический s/ω_t | ⟨φ₁²⟩ за 40/ω_t |
|---|---|---|---|---|
| обычная π-петля | 0.5 | 0 | 0.71 | 0.012 → 1.15 |
| гиратор, без пружины («Рэлей») | 0 | 3 | 0 | остаётся 0.012–0.013 |
| гиратор + слабая пружина (МРН) | 0.47 | 3 | 0.17 | 0.012 → 1.29 |
| гиратор + сильная пружина | 1.3 | 3 | 0 | ≤ 0.026 (колебания) |

Квантовые нулевые колебания играют роль начального возмущения: в окне неустойчивости они экспоненциально
усиливаются с классическим инкрементом. Без затравки распределение остаётся симметричным: в конце это
«восьмёрка» с двумя долями вокруг минимумов потенциала ±φ₁* (рис. (d)) — кошачье состояние, вращающееся
под действием гиратора.

## Оговорки
* Система замкнутая, без диссипации, поэтому после неустойчивости она не оседает в минимуме, а колеблется
  (в диске насыщение даёт турбулентность). С диссипацией гироскопически стабилизированное состояние при K = 0
  тоже, вероятно, неустойчиво: отрицательная энергия эпициклической моды (как магнетронная мода ловушки Пеннинга).
  Это не проверялось.
* При K = 0 есть нулевая мода (равномерный дрейф φ₂, аналог соседней круговой орбиты), поэтому волновой пакет
  расплывается по φ₂: к концу счёта у края сетки вес 10⁻³.
* Гиратор в сверхпроводящей схеме — холловский (Viola, DiVincenzo 2014) или параметрический; нужна
  ω_c ≳ ω_t ~ плазменной частоте петли. Реализуемость этих значений не оценивалась.
