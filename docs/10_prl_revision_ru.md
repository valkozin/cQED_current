## 2. Новая физика: нулевые колебания потока переключают переход 0→π

Раздел `paper/cavity0pi.tex`, рисунок `figs/fig_cavity_0pi.pdf`, данные `data/nonadiabatic/`, код
`code/run_nonadiabatic.py`, `code/analyze_nonadiabatic.py`.

* Режим ħω ~ E_A (для Al: ħω = 0.03–0.3Δ это 1–13 ГГц, обычные частоты), g = 0–1 (Z до 8 кОм).
  Полный DMRG в обоих секторах чётности при φ_cl = 0 без затравки; граница петли U_c(g, ω) — из
  пересечения E_odd = E_even (линейно по U между узлами; наклон ≈ −0.26/Δ, линейность проверена).
* Два предела: адиабатический (circuit model, ур. (BO) с E_s(φ) при g=0: синглет теряет, дублет выигрывает
  нулевую энергию g²E''_s(0)/2) и антиадиабатический (Ланг–Фирсов: t_J → t_J e^{−g²/2}, т.е. Γ → Γe^{−g²},
  синглет, связанный Γ, проигрывает). Точное решение интерполирует между ними.
* Результаты (`data/nonadiabatic/summary.json`, χ=200, ошибка усечения <4·10⁻⁷, вес последнего фоковского
  уровня <4·10⁻⁸). Граница петли U_c(g, ω)/Δ (U_c⁰ = 0.941):

  | ħω/Δ | g=0.2 | g=0.4 | g=0.6 | g=0.8 | g=1.0 | circuit model при g=0.8 | LF при g=0.8 |
  |---|---|---|---|---|---|---|---|
  | 0.01 | 0.925 | 0.889 | 0.848 | 0.813 | 0.783 | 0.815 | 0.670 |
  | 0.03 | – | 0.880 | – | 0.776 | – | 0.782 | |
  | 0.1 | 0.921 | 0.868 | 0.798 | 0.724 | 0.652 | 0.739 | |
  | 0.3 | 0.919 | 0.859 | 0.775 | 0.683 | 0.597 | 0.715 | |
  | 1.0 | 0.918 | 0.853 | 0.762 | 0.663 | 0.573 | 0.703 | 0.670 |
  | 3.0 | 0.917 | 0.852 | 0.761 | 0.662 | 0.573 | 0.700 | 0.670 |

  Предел Ланга–Фирсова (U_c при g = 0.2…1.0): 0.918, 0.854, 0.765, 0.670, 0.584 — совпадает с точным решением
  при ħω ≥ Δ до 0.01Δ (кроссовер насыщается при ħω ≈ Δ). Важно: уменьшение t_J e^{−g²/2} относится только к
  одетой фотоном связи (0,1); первая версия опорного расчёта уменьшала обе связи точки и давала линию
  (0.428 при g=0.8), которую точное решение не достигало — проверка при ħω = 3Δ это выявила.
  Проверки: χ=300 меняет энергии на <5·10⁻⁶Δ, N_ph=40–80 на <10⁻⁷Δ, промежуточные узлы по U сдвигают U_c на <10⁻³Δ.

  При U = 0.9Δ, ħω = 0.1Δ: E_odd − E_even = +0.010Δ (g=0) → −0.008Δ (g=0.4) → −0.065Δ (g=1); переключение
  при g ≈ 0.28 (Z ≈ 0.6 кОм). В адиабатическом пределе точное решение совпадает с circuit-моделью до 0.002Δ;
  с ростом ħω граница уходит от неё (на 0.015, 0.032, 0.040Δ при g=0.8 для ħω = 0.1, 0.3, 1Δ) и ложится на линию
  Ланга–Фирсова при ħω ≈ Δ. Сдвиг при ħω = 0.01Δ (ёмкостные поправки пренебрежимы) — половина сдвига при 0.3Δ, т.е. эффект
  не артефакт одно-bond вершины.
* Экспериментальная сигнатура: скачок частоты резонатора (0 → π) при фиксированном затворе, управляемый
  импедансом суперндуктора.

## 3. Исправления по разбору

* **Калибровка.** «Вся фаза на связи по выбору калибровки» заменено на утверждение о схеме: статическую фазу
  можно разнести по кольцу (ковариантно для Δ), квантовую — нет (Dmytruk–Trif–Simon PRB 94, 115423 (2016)):
  возникают члены ħω(λNP + λ²N²) — ёмкостная связь. Модель = напряжение моды падает на переходе.
  Отброшенные члены ~ ħωg²/E_A. Текст: `body.tex` (Model), `supplement.tex` S1.
* **Единицы.** Параметры диаграммы (U=2Δ, Γ=Δ/2) дают ħω = E_J/10 = 32 МГц для Al (1.5 мК): недостижимо.
  Честно сказано; для режима конденсата/кошки взят сильный переход t_J = t, U = 6Δ на NbTiN/Nb
  (E_J/h ≈ 10 ГГц, I_c ≈ 20 нА, ħω ≈ 1 ГГц, L ≈ 17 нГн, Z ≈ 160 Ом); таблица в SM S6. Выдуманный класс
  «multichannel π junctions with I_c ~ 50–200 nA» убран.
* **«The interaction-driven realization has no such requirement»** убрано: паразитный поток δΦ > δ/2I*
  поляризует любую петлю; π-переход снимает лишь нужду в смещении Φ0/2.
* **Спин-орбита.** 4-кратный мультиплет только без SOI; с SOI ямы спин-привязаны (del Olmo 2026), остаётся
  крамерсова пара; наша модель — микроскопика IPA-кубита.
* **Затравка.** Карта (U,g) дополнена затравко-независимым параметром порядка — δ(U,g) эффективной модели
  (`code/make_fig_main.py`, `figs/fig_phase_main.pdf`); сказано, что затравленный ток — диагностика кроссовера.
* **δ при β ≥ 2.** Проверено решателем по чётности потока (`code/bo_parity.py`, `data/bo_parity_U2_Nr10.json`):
  при E_J/ħω = 10 значения 8·10⁻⁷ (β=2) и 6.5·10⁻⁹ (β=3) надёжны (два метода совпадают до 1%); пол
  ~10⁻⁹ħω достигается только при E_J/ħω = 40.
* **π′-окно** 0.85Δ < U < 0.94Δ названо по Vecino 2003 / Karrasch 2008.
* **Nataf et al. PRL 123, 207402** больше не цитируется как no-go (это «go»-работа); no-go: Andolina 2019,
  для схем Nataf–Ciuti 2010, Viehmann 2011.
* **Ссылка [notebook]** убрана; метод MF описан в SM S5.
* **E_2 ∝ U^{−1.3}** — сказано «approaching 1/U of cotunnelling».
* **Формат.** Основной текст: аннотация, введение, 4 рисунка (обзор, 0–π переключение, диаграмма, кошка),
  ~3000 слов + подписи; остальное (методы, слабая связь + Φ0/2, модель ноутбука, сходимость, срезы, единицы)
  в Supplemental Material (`paper/supplement.tex`). Название: «Zero-point flux fluctuations switch a
  quantum-dot Josephson loop from 0 to π».
* **Баг кода.** `observables()` считала энтропию запутанности фотона на левой границе MPS (всегда 0);
  исправлено (спектр ρ_ph). В статье эта величина раньше не использовалась.
