# Фазовая диаграмма при ħω = 0.01 t: полный DMRG с фермионным током

Рисунок: `figs/fig_phase_diagram_om0.01.pdf`. Код: `code/run_dmrg_point.py` (одна точка), `cluster/run_local.sh`
(сетка; `cluster/dmrg_om0.01.sbatch` — то же для Slurm), `code/phase_diagram_om.py` (адиабатика и MF),
`code/make_figures_om.py`. Данные: `data/om0.01/*.json`, `data/phase_diagram_om0.01.json`.

## Что посчитано
Модель Eq. (1) (L=14, t=1, Δ=t, t_J=0.5t, ε_d=−U/2), ħω = 0.01 t (в 13 раз больше, чем 7.61·10⁻⁴ t в статье),
затравка φ_cl = 10⁻³. Полный DMRG «электроны + фотон» (N_ph = 20), ток — среднее микроскопического фермионного
оператора на переходе:

    I = −∂H/∂φ_cl = i t_J Σ_σ ⟨e^{iφ_cl} e^{ig(a+a†)} c†_{1σ} c_{0σ} − h.c.⟩.

* Разрез U = 2t: g = 0.05…1.2 (шаг 0.05), χ = 64→128→256, плюс первое возбуждённое состояние (δ).
* Грубая сетка: U ∈ {1, 1.5, 3, 4, 6, 8} × g ∈ {0.1…1.2}, χ = 64→128.
* Всего 96 точек, ~1.5 ч на 4 ядрах облачной машины.

## Проверки
* Тот же оператор на кольце из 4 узлов + фотон = точная диагонализация до 10⁻¹².
* Тождество ⟨I⟩ = ħω⟨X⟩/2g (выполняется только в точном собственном состоянии): при U=2, χ=256 — до ~10⁻³
  относительно; на грубой сетке (χ=128) — 0.1–2% при |I| ≳ 10⁻⁵, до ~15% в точках с |I| ~ 10⁻⁶ (g ≳ 1.1).
* Изменение тока при χ 128→256 на разрезе U=2 < 1%.
* Полный DMRG = адиабатической теории: U=2, g=0.2: 3.548·10⁻⁵ / 3.55·10⁻⁵; U=1, g=0.5: 1.243·10⁻⁴ / 1.24·10⁻⁴;
  δ/ħω при U=2: 0.883 / 0.88 (g=0.2), 0.541 / 0.542 (g=0.5).
* При ħω = 7.6·10⁻⁴ t этот же оператор давал |I| ≫ I_c выше порога (docs/04, п. 4): там щель фотона мала по
  сравнению с ошибкой энергии DMRG. При ħω = 0.01 t проблемы нет.

## Результат
При ħω = 0.01 t спонтанного тока нет нигде на плоскости (U, g). E_J/ħω = 1.1 (U=1), 0.76 (U=2), 0.24 (U=6),
т.е. всюду ≲ 1: нулевые колебания потока восстанавливают симметрию.
* Ток — линейный отклик на затравку: |⟨I⟩| ≤ 1.2·10⁻⁴ et/ħ (U=1), ≤ 4.8·10⁻⁵ (U=2) против ≈1.4·10⁻² при
  ħω = 7.6·10⁻⁴ t; адиабатическая теория даёт ⟨I⟩ ∝ φ_cl (затравка 10⁻⁵ → ток в 100 раз меньше).
* δ/ħω ≥ 0.33 на всей диаграмме (≥ 0.5 при U=2), ⟨a†a⟩ ≤ 0.35.
* Классическая линия β = 1 (g_c = 0.33 при U=1, 0.41 при U=2) пересекается без какого-либо скачка.
* Среднее поле при той же частоте по-прежнему предсказывает фазу с током (|I| до 0.02 при U=1, 0.012 при U=2,
  ⟨a†a⟩ ≈ 1–2) — качественно неверно.
