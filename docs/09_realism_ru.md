# Насколько реалистичны результаты: перевод в физические единицы

Параметры «выраженного» режима (docs/07): t_J = t, U = 6t, ε_d = −U/2, Δ = t, ħω = 0.003 t, g ≈ 0.12–0.14.
Перевод: t = Δ реального сверхпроводника.

## Параметры перехода
* Γ (полуширина уровня, оба контакта) ≈ 2t_J²/t = 2Δ; U = 6Δ; U/Γ = 3, точка электрон-дырочной симметрии.
  Порядок величин типичен для дотов в InAs-нанопроволоках и УНТ (U ~ 1–10 мэВ, Γ ~ 0.1–2 мэВ).
* Дублет ниже синглета на 0.044Δ — мы вблизи границы 0–π, где E_J дублета максимальна. Работа требует
  гейтовой подстройки ε_d и Γ.
* Модель — одномерная цепочка с Δ = t (ξ ~ пара узлов, ширина зоны 4Δ, Δ фиксировано). Качественно π-переход
  на дублете — известная физика (Glazman–Matveev, Vecino 2003, Karrasch 2008, NRG). Количественно E_J(U/Δ, Γ/Δ)
  в пределе широкой зоны может отличаться (оценка без расчёта: десятки процентов).

## Масштабы (python: см. сессию; g = 0.14 для барьера)

| | Al (Δ = 180 мкэВ) | NbTiN (Δ ≈ 1.2 мэВ) |
|---|---|---|
| E_J/h (E_2 cos θ) | 1.5 ГГц | 9.9 ГГц |
| I_c | 3.0 нА | 20 нА |
| ħω/h, ħω/k_B | 0.13 ГГц, 6 мК | 0.87 ГГц, 42 мК |
| барьер двойной ямы (BO, g = 0.14) | 4.3ħω ≈ 27 мК | ≈ 180 мК |
| Z моды ((2g)² = πZ/R_Q) | 161 Ом | 161 Ом |
| L, C петли | 196 нГн, 7.6 пФ | 29 нГн, 1.1 пФ |
| β = 2πLI_c/Φ0 | 1.8 | 1.8 |
| поток при I = 0.94 I_c | 0.27 Φ0 | 0.27 Φ0 |

Вывод: с Al режим E_J/ħω ≈ 13 требует ħω ≈ 130 МГц, что ниже электронной температуры (20–50 мК); барьер
(27 мК) сравним с T. На NbTiN (или Nb) все масштабы в 6–7 раз выше: ħω ≈ 0.9 ГГц, барьер ≈ 180 мК,
L ≈ 30 нГн (кинетическая индуктивность), Z ≈ 160 Ом — стандартная схема (π-rf-SQUID с β ≈ 1.8).
Нужны U ≈ 7 мэВ и Γ ≈ 2.4 мэВ — для коротких дотов достижимо, но с NbTiN известна проблема «мягкой щели».

## Что это физически
* «Фотонный конденсат» ⟨a†a⟩ ≈ 9 — это статический поток в петле (когерентное смещение моды), а не излучение.
  Устройство — π-rf-SQUID с β > 1 при нулевом внешнем потоке (Bulaevskii–Kuzii–Sobyanin 1977; спонтанные
  токи в SFS- и d-волновых петлях наблюдались). Новое: π за счёт U в доте и квантовый режим E_J/ħω ~ 1–10.
* Компромисс фундаментальный: при E_J/ħω ≈ 13 ток выраженный, но δ ~ 10⁻¹⁰ ħω — это классическая
  бистабильность (гистерезис по потоку, симметричный относительно Φ = 0). Наблюдаемое туннелирование
  (δ ~ 10⁻³–10⁻¹ ħω) требует E_J/ħω ~ 2–5, где ток слабый и зависит от смещения потока.
* Сигнатура в эксперименте: бистабильность и гистерезис вокруг Φ_ext = 0 (у обычной π-петли — вокруг Φ0/2),
  поток ~0.27 Φ0 (легко измерить SQUID-магнитометром или дисперсионно); направление выбирает фоновый поток
  ~10⁻³ Φ0.

## Риски
* Отравление квазичастицами / переключения чётности дублет ↔ синглет (= π ↔ 0); известно по андреевским спиновым
  кубитам, времена мкс–мс.
* Свободный спин дота (Крамерс) — чувствителен к магнитному полю.
* Тепловая заселённость моды и термоактивация через барьер — главный ограничитель для Al.
* Модель: одна мода, без диссипации, T = 0, гальваническая связь (k = 1); при k < 1 эффективная связь меньше.

## Аналог МРН (docs/08)
Нужно ω_c > ω_t, т.е. G·Z_J > 1, Z_J = √(L_J/C). L_J = (ħ/2e)²/E_J ≈ 110 нГн (Al), 17 нГн (NbTiN).
С холловским гиратором R_H = h/(νe²): при ν = 1 нужна C < 0.17 фФ (Al) / 0.02 фФ (NbTiN), при ν = 6 —
C < 6 фФ / 0.9 фФ. Плюс квантово-холловский режим требует полей ~ Тл, несовместимых с Al.
Квантовая реализация со статическим гиратором сейчас нереалистична; возможны синтетические гироскопические
связи (параметрическая модуляция, джозефсоновские циркуляторы) в эффективном гамильтониане вращающейся
системы отсчёта или классическая демонстрация на обычной электронике.
